# sajang · 옆집 사장님의 AI 실습장

2026-10-26 서울신용보증재단 소상공인 공개강좌 「AI 잘 쓰는 옆집 사장님의 비밀 전략 A to Z」 실습 페이지.

## 배포 (GitHub Pages)
1. github.com/socialkim 에서 새 저장소 `sajang` 만들기 (Public)
2. 이 폴더 안의 파일 전부(index.html, img/, data/)를 그대로 올리기
3. Settings → Pages → Branch: main / root → Save
4. 1~2분 뒤 https://socialkim.github.io/sajang/ 접속 확인 → 이 주소로 QR 만들어 덱 26·57장에 붙이기

## 들어 있는 것
- index.html: 실습 1~3, 토크콘서트 5상황 따라 하기, 더 해 보기 6문장, 오늘 저녁 체크리스트
- calculator.html: 메뉴 이익 계산기(덱 44장 바이브코딩 시연 결과물)
- data/: 실습용 가상 자료 8개(영문 파일명)
- img/: 힉스필드 삽화 11장
